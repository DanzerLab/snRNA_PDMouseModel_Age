# LuciAge
Code Repository for the paper "Targeting Cdc42 Improves Motor Phenotype in Parkinson’s Disease Mice and Reveals Age-Dependent Susceptibility to α-Synuclein"

The raw sequencing data that was generated in this study is available from ArrayExpress with the identifier E-MTAB-14889. Detailed metadata, the processed single-cell data and all other source data are available on Zenodo (https://doi.org/10.5281/zenodo.14893737).
